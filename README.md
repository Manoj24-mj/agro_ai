## 📖 About
**Agro AI** is an AI-powered smart agriculture platform designed to help farmers make better farming decisions using artificial intelligence. The application detects crop diseases from plant images and provides accurate disease diagnosis, treatment recommendations, and preventive measures. It also offers weather updates, fertilizer guidance, pest management, and multilingual support to improve accessibility for farmers.

## 🎯 Objectives
- Detect crop diseases using AI.
- Recommend suitable treatments and preventive measures.
- Improve crop productivity through smart recommendations.
- Provide farmers with an easy-to-use digital agriculture assistant.

## ✨ Features
- 🌿 AI-powered crop disease detection
- 📷 Plant image upload and analysis
- 🩺 Disease diagnosis with confidence score
- 💊 Treatment and prevention recommendations
- 🌾 Fertilizer recommendations
- 🐛 Pest management suggestions
- 🌦️ Weather information
- 🌍 Location-based farming insights
- 🗣️ Multilingual support

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/Manoj24-mj/agro_ai.git
```

### Open Project

```bash
cd agro_ai
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Application

```bash
python app.py
```

Open your browser and visit:

```
http://localhost:5000
```
